# Social research loop rules (owner request 2026-11-03)

Goal: a sourced baseline of what works for basketball stats/analytics accounts (EuroLeague and NBA) on social media: posts per day, videos vs photos, topics, voice, animation styles, hooks, captions, engagement.

Every agent:
1. Runs 30 iterations. One iteration = one lead researched and written down. Persist after EVERY iteration (append to your findings file and scoreboard) so the work survives if you stop.
2. Rising bar: each iteration must add NEW, SOURCED evidence: a newly profiled account (handle, platform, followers, posting frequency, format mix, 2-3 example posts/videos and why they worked) or a pattern backed by >= 2 independent sources. Gain = number of new sourced data points. Each iteration's gain must be >= the median gain of your earlier iterations. If a lead dries up, switch to a harder or different lead (another account tier, platform, language, a viral-post analysis), never repeat or pad.
3. Every claim has a source URL and the date you read it. Numbers you could not verify are marked "estimate" with how you estimated. Never invent handles, follower counts or posts. Login walls (Instagram/TikTok/X) are expected: use public profile pages if fetchable, Social Blade / similar stats sites, articles, case studies, YouTube, Reddit threads, Google results snippets.
4. Scoreboard row per iteration: `| iter | lead | new data points | cumulative | accounts profiled (cum) | notes |`.
5. At iterations 10, 20 and 30 write a "Synthesis so far" section: the baseline (posts/day, video vs image share, top topics, voice/tone, animation styles, hook patterns, caption length, hashtags, best times) with confidence (high/medium/low) and which findings support it.
6. Read-only on the codebase. Write only to your own files in docs/research/social/. No git commits.
7. Copyright: note which accounts use league footage/logos (legal risk for us) vs original data graphics (what we can copy as a format).
